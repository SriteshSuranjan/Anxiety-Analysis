# Anxiety Analysis Using Machine Learning 🧠📊

## 📌 Overview  
This project analyzes anxiety levels using machine learning techniques. The dataset is preprocessed, and various machine learning models are used for classification.

## 🚀 Features  
✅ Dataset preprocessing and feature engineering  
✅ Implementation of multiple ML models (SVC, Naïve Bayes, Random Forest)  
✅ K-Fold Cross Validation for evaluation  
✅ Data visualization for insights  

## 🛠 Technologies Used  
- Python  
- Jupyter Notebook  
- Scikit-learn  
- Pandas  
- NumPy  
- Matplotlib  

## 📊 Dataset  
The dataset contains features related to psychological, social, and behavioral factors influencing anxiety. Preprocessing steps include handling missing values, normalizing data, and feature selection.
